Carga de un objeto mediante un módulo

Como un módulo sólo se carga y ejecuta una única vez, un módulo que devuelva un objeto de una clase siempre devolverá el mismo objeto (aunque importemos el módulo varias veces).

En el código de ejemplo se importa un par de veces el módulo Punto2D que devuelve un objeto de tipo Punto2D.

A continuación se cambian las coordenadas de uno de los dos puntos importados y se imprimen los puntos en la división de abajo para que se vea que son el mismo objeto.
